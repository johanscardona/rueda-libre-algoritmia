# Rueda Libre - Asistente de Taquilla v0.1

Este repositorio contiene los algoritmos y la documentación base desarrollados para la gestión operativa y financiera del local de alquiler de bicicletas **Rueda Libre** (Medellín).

## 🚀 Contenido del Proyecto
- `bitacora.md`: Contiene el algoritmo base en lenguaje natural, análisis de requerimientos, pruebas de escritorio paso a paso y la descomposición técnica de los retos matemáticos.
- `diagramas/`: Carpeta con la representación visual e imágenes de la lógica algorítmica.
- `algoritmos/`:
  1. `01_cotizacion_basica.psc`: Módulo secuencial para el cálculo simple de renta por horas de bicicletas urbanas.
  2. `02_cotizacion_recorrido.psc`: Módulo enfocado en la gestión de cotizaciones y anticipos del 30% para recorridos guiados.
  3. `03_cuenta_grupo.psc`: Asistente unificado v0.1 que realiza cálculos de cuentas grupales compartidas con aportes de mantenimiento e implementación de redondeo al techo por centenas.

## 💻 Instrucciones de Apertura
1. Descargue los archivos `.psc` de la carpeta `algoritmos/`.
2. Instale y abra el software **PSeInt**.
3. Vaya a `Archivo > Abrir` y seleccione el componente deseado.
4. Asegúrese de tener configurado el perfil de lenguaje **Estricto** para validar la correcta definición inicial de variables.
